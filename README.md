# My IR Page

HTML / CSS / JavaScript を使用して作成した自己紹介ページです。

## 概要

平成レトロな雰囲気を意識し、カード形式のレイアウトや余白、配色にこだわって制作しました。

## 工夫した点

- カード形式で情報を整理し、読みやすいデザインにしました
- ホバー時の変化や、クリック時の吹き出し表示など、触って楽しい動きを実装しました
- スマートフォンでも見やすいようにレスポンシブ対応を行いました

## 使用技術

- HTML
- CSS
- JavaScript
